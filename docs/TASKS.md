## 进入正式开发前的风险门槛

- [ ] SEC-01｜待开始：核实公开可写/管理读取/上传的部署暴露面，若仍可达先隔离 S-01、S-02。验收：匿名无法读管理内容、改文章/设置、发上传令牌或上传；公开文章与保留互动不受破坏。先独立小任务，不把全部认证系统塞进隔离修复。
- [ ] SEC-02｜待开始：修复两份提示组件不可信 HTML 渲染。验收：URL/存储/API 消息均作为文本、variant 白名单、pending/resolved 正常；教学只用无害标记验证。
- [ ] SEC-03｜待开始：停用破坏性迁移路径并设计非破坏 dry-run/备份。验收：空响应/转换失败不删除原稿，草稿不入公开产物。运行任何真实迁移另获授权。

这些风险处理建议不扩展本轮“只审查”的授权；新业务上线前必须完成对应门槛。
