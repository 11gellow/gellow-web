# 博客欢迎页

分支：codex/blog-welcome-stage。

首次打开或刷新博客首页，加载动画结束后显示全屏欢迎页。头像与名牌采用错位排版，顶部为施工警示滚动条，中下方语录逐字出现并循环掉落。

## 自定义语录

编辑 `.vitepress/theme/welcome.ts` 的 `welcomeQuotes` 数组，每个字符串是一条语录。建议每条 15–35 个字。

当前时序：每字 85ms → 完整停留 2.2 秒 → 字符按随机延迟、水平初速度、向上初速度与角速度逐个自由落体 → 离开屏幕 1 秒后清除 → 300ms 后开始下一句。每轮重新随机，不使用固定预录轨迹。

## 进入文章列表

向下滚轮、向上滑动触屏、点击底部圆形箭头、按方向下键/PageDown/空格/End 都可进入。欢迎页和收拢期间页面不滚动，约 1.15 秒的收拢过渡结束后解除滚动锁。

收拢目标取实际列表页身份卡片、头像、名牌的屏幕坐标。列表已在背后渲染，遮挡面板四边向身份卡片收缩，逐渐露出列表。动画中窗口缩放会直接完成进入，避免停在过期坐标。

同一站内会话从文章返回不重复展示；刷新页面重新展示。播放器仍在全局 Layout 中，不重建音频，层级高于欢迎页；播放器内滚轮与按键不会触发首页跳转。组件卸载清理动画、事件和滚动锁。

系统开启减少动态效果时，语录静态轮播、入口直接切换，避免强制大幅移动。后台标签页暂停语录动画。

验证：生产构建通过；桌面滚轮触发时 scrollY 保持 0，过渡结束后锁释放并能滚动；文章返回不重复欢迎页；390px 宽度无横向溢出。构建仍有项目既存的图片引用和大 chunk 警告。
