# 黑胶音乐播放器

播放器常驻于主题 Layout，通过 Teleport 放在 body 下，层级为 2000，高于加载动画。站内导航使用 VitePress 路由，页面切换不会重新创建音频元素。

- 默认在左侧、屏幕高度约三分之二处，露出三分之一。
- 单张黑胶唱片使用 Gellow 形象，唱片和面板头像持续旋转。悬停展开至五分之四并上移，显示深色圆角、橙色控制面板；点击唱片可固定展开，面板右上角可收起。
- 选择本地音频文件，可多选组成歌单。音频只通过浏览器 Blob URL 播放，不上传。
- 支持播放、暂停、上一首、下一首、进度拖动、音量和歌单选择；播放结束循环切歌。
- 歌单在本次站内浏览期间保留。手动刷新、关闭页面或跳转其他网站会终止播放并清空本地歌单。
- 默认曲目为用户提供的卡农测试音频，静态文件位于 assets/music/canon.mp3，头像位于 assets/music/gellow-cover.png。打开博客后自动尝试有声播放；若浏览器拦截，会在首次页面点击或按键时重试。手动暂停后不会由页面点击自动恢复。歌单按钮可展开列表并添加本地音乐；循环按钮切换列表循环和单曲循环。

验证：使用生成的两分钟静音 WAV，在列表→文章→列表→浏览器后退过程中，音源不变，播放时间连续增长，未暂停。
