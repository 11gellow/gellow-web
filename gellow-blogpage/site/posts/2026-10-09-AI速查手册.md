## 1. 基础神经网络架构

| 缩写 / 英文名称 | 中文名称 | 核心概念 / 用途 |
|---|---|---|
| **ANN** — Artificial Neural Network | 人工神经网络 | 神经网络的宽泛总称。 |
| **DNN** — Deep Neural Network | 深度神经网络 | 具有多个隐藏层的神经网络。 |
| **FNN** — Feedforward Neural Network | 前馈神经网络 | 信息沿输入到输出方向传播，无循环连接。 |
| **MLP** — Multi-Layer Perceptron | 多层感知机 | 常见前馈网络，也经常作为其他架构内部模块。 |
| **CNN / ConvNet** — Convolutional Neural Network | 卷积神经网络 | 用卷积提取局部空间特征。 |
| **RNN** — Recurrent Neural Network | 循环神经网络 | 通过隐藏状态处理有顺序的数据。 |
| **LSTM** — Long Short-Term Memory | 长短期记忆网络 | 使用门控缓解传统 RNN 的长期依赖问题。 |
| **GRU** — Gated Recurrent Unit | 门控循环单元 | 结构相对简洁的门控 RNN。 |
| **Transformer** | Transformer / 变换器架构 | 以注意力机制为核心，广泛用于语言、视觉和多模态。 |
| **GNN** — Graph Neural Network | 图神经网络 | 对节点、边与图结构进行学习。 |
| **SNN** — Spiking Neural Network | 脉冲神经网络 | 使用脉冲信号建模神经活动。 |
| **SSM** — State Space Model | 状态空间模型 | 通过状态演化描述序列信息；现代序列架构常借鉴此类思想。 |

**基础关系**：卷积（Convolution）是一种运算；CNN 是使用卷积构成的一类网络；ConvNet 基本是 CNN 的别称。

## 2. 卷积网络与视觉骨干

| 英文名称 | 中文名称 | 核心概念 / 用途 |
|---|---|---|
| **LeNet** | LeNet 卷积网络 | 早期 CNN，经典手写数字识别架构。 |
| **AlexNet** | AlexNet 网络 | 推动深度 CNN 在图像分类中普及。 |
| **VGG / VGGNet** | VGG 网络 | 堆叠小卷积核，结构规则。 |
| **ResNet** — Residual Network | 残差网络 | 使用残差连接训练深层网络。 |
| **Inception / GoogLeNet** | Inception 网络 | 并行卷积分支提取多尺度信息。 |
| **DenseNet** — Densely Connected Network | 密集连接网络 | 不同层之间密集连接、复用特征。 |
| **MobileNet** | 移动端轻量网络 | 采用深度可分离卷积等技术降低计算量。 |
| **EfficientNet** | 高效卷积网络 | 综合缩放深度、宽度和输入分辨率。 |
| **ConvNeXt** | 现代化卷积网络 | 吸收现代视觉架构设计经验的 CNN。 |
| **U-Net** | U 形网络 | 编码器—解码器及跳跃连接，常用于分割。 |

## 3. 视觉 Transformer 与自监督视觉学习

### 3.1 视觉 Transformer 家族

| 缩写 / 英文名称 | 中文名称 | 核心概念 / 用途 |
|---|---|---|
| **ViT** — Vision Transformer | 视觉 Transformer | 将图像切成 Patch，再以 Transformer 学习特征。 |
| **DeiT** — Data-efficient Image Transformer | 数据高效视觉 Transformer | 通过训练策略、蒸馏提高数据利用效率。 |
| **Swin Transformer** — Shifted Window Transformer | 移位窗口 Transformer | 分层结构与移位窗口注意力。 |
| **PVT** — Pyramid Vision Transformer | 金字塔视觉 Transformer | 多尺度视觉特征，适合检测、分割。 |
| **BEiT** — Bidirectional Encoder representation from Image Transformers | 图像 Transformer 双向编码表示 | 基于图像预训练学习视觉表征。 |
| **MAE** — Masked Autoencoder | 掩码自编码器 | 遮挡并重建图像块的自监督训练方法。 |
| **DINO / DINOv2** | 自蒸馏视觉表征方法及模型 | 无需人工类别标签学习通用视觉特征。 |

### 3.2 自监督与对比学习方法

| 缩写 / 英文名称 | 中文名称 | 核心概念 / 用途 |
|---|---|---|
| **SimCLR** — Simple Framework for Contrastive Learning of Visual Representations | 简单对比视觉表征学习框架 | 拉近同一图像不同增强视图的特征。 |
| **MoCo** — Momentum Contrast | 动量对比学习 | 动量编码器与特征队列。 |
| **BYOL** — Bootstrap Your Own Latent | 自举式潜在表征学习 | 不显式使用负样本的自监督方法。 |
| **Barlow Twins** | 巴洛双生网络 | 通过约束特征相关性减少冗余。 |
| **iBOT** — Image BERT Pre-Training with Online Tokenizer | 在线分词器图像 BERT 预训练 | 掩码图像建模与自蒸馏。 |
| **I-JEPA** — Image Joint Embedding Predictive Architecture | 图像联合嵌入预测架构 | 预测被遮挡区域的抽象特征，而非直接重建像素。 |
| **SigLIP** — Sigmoid Loss for Language-Image Pre-training | Sigmoid 损失图文预训练 | 通过成对 Sigmoid 损失学习图文关联。 |

> MAE、DINO、SimCLR、MoCo 等通常描述**训练方法或由该方法训练的模型**，并非都属于与 ViT 同级的网络架构。

## 4. 目标检测与图像分割

### 4.1 目标检测（Object Detection）

| 缩写 / 英文名称 | 中文名称 | 核心概念 / 用途 |
|---|---|---|
| **R-CNN** — Region-based CNN | 基于区域的卷积神经网络 | 使用候选区域进行目标检测。 |
| **Fast R-CNN** | 快速区域卷积网络 | 共享卷积特征，降低候选区域处理成本。 |
| **Faster R-CNN** | 更快速区域卷积网络 | 引入区域提议网络（RPN）。 |
| **YOLO** — You Only Look Once | YOLO 检测模型系列 | 侧重实时检测；不同版本架构不完全相同。 |
| **SSD** — Single Shot MultiBox Detector | 单阶段多框检测器 | 在多尺度特征上直接预测目标。 |
| **RetinaNet** | RetinaNet 检测网络 | 使用 Focal Loss 处理类别不平衡。 |
| **DETR** — Detection Transformer | 检测 Transformer | 使用 Transformer 和集合预测实现检测。 |
| **RT-DETR** — Real-Time DETR | 实时检测 Transformer | 面向实时目标检测优化。 |
| **DINO（检测）** — DETR with Improved deNoising Anchor Boxes | 改进去噪锚框的检测 Transformer | 改进 DETR 的查询与训练方式。 |

### 4.2 图像分割（Image Segmentation）

| 缩写 / 英文名称 | 中文名称 | 核心概念 / 用途 |
|---|---|---|
| **FCN** — Fully Convolutional Network | 全卷积网络 | 用于像素级语义分割。 |
| **DeepLab** | DeepLab 分割模型系列 | 使用空洞卷积等技术提取密集特征。 |
| **Mask R-CNN** | 掩码区域卷积网络 | 在检测之外预测实例的像素掩码。 |
| **Mask2Former** | 掩码注意力 Transformer | 统一多类图像分割任务。 |
| **SAM** — Segment Anything Model | 分割一切模型 | 基于点、框等提示分割图像。 |
| **SAM 2** — Segment Anything Model 2 | 分割一切模型 2 | 扩展提示式分割到图像和视频。 |

**任务区别**：分类＝识别类别；检测＝识别类别和位置；分割＝确定属于目标的像素。

## 6. 自然语言处理与大语言模型

### 6.1 Transformer 架构模式

| 英文名称 | 中文名称 | 特征 / 代表 |
|---|---|---|
| **Encoder-only** | 仅编码器 | 侧重输入理解与特征表示；BERT、RoBERTa。 |
| **Decoder-only** | 仅解码器 | 常用于自回归生成；GPT、Llama、Qwen 语言模型。 |
| **Encoder-Decoder** | 编码器—解码器 | 输入编码后生成输出；T5、BART。 |

### 6.2 常见语言模型家族

| 缩写 / 英文名称 | 中文名称 | 核心概念 / 用途 |
|---|---|---|
| **BERT** — Bidirectional Encoder Representations from Transformers | Transformer 双向编码表示 | 经典语言理解模型。 |
| **RoBERTa** — Robustly Optimized BERT Pretraining Approach | 鲁棒优化的 BERT 预训练方法 | 改进 BERT 的训练策略。 |
| **ALBERT** — A Lite BERT | 轻量化 BERT | 通过参数共享等方式减少参数。 |
| **GPT** — Generative Pre-trained Transformer | 生成式预训练 Transformer | 自回归生成模型家族。 |
| **T5** — Text-to-Text Transfer Transformer | 文本到文本迁移 Transformer | 将多种任务统一成文本输入与输出。 |
| **BART** — Bidirectional and Auto-Regressive Transformers | 双向与自回归 Transformer | 结合双向编码器和自回归解码器。 |
| **Llama** — Large Language Model Meta AI | Meta 大语言模型系列 | 开放权重语言模型家族。 |
| **Qwen** | 通义千问模型系列 | 覆盖文本、代码与多模态的模型家族。 |
| **DeepSeek** | 深度求索模型系列 | 包括通用、推理及 MoE 模型等。 |
| **Mistral** | Mistral 模型系列 | 包括稠密与混合专家模型。 |

## 8. 生成式模型

| 缩写 / 英文名称 | 中文名称 | 核心概念 / 用途 |
|---|---|---|
| **AE** — Autoencoder | 自编码器 | 编码数据并重建输入，不必然是概率生成模型。 |
| **VAE** — Variational Autoencoder | 变分自编码器 | 学习概率潜在表示并生成数据。 |
| **GAN** — Generative Adversarial Network | 生成对抗网络 | 生成器与判别器对抗训练。 |
| **DCGAN** — Deep Convolutional GAN | 深度卷积生成对抗网络 | 使用 CNN 构造 GAN。 |
| **StyleGAN** | 风格式生成对抗网络 | 通过风格控制图像生成。 |
| **Diffusion Model** | 扩散模型 | 学习逐步去噪生成数据。 |
| **DDPM** — Denoising Diffusion Probabilistic Model | 去噪扩散概率模型 | 经典扩散生成框架。 |
| **LDM** — Latent Diffusion Model | 潜在扩散模型 | 在压缩后的潜在空间进行扩散。 |
| **DiT** — Diffusion Transformer | 扩散 Transformer | 使用 Transformer 作为扩散模型骨干。 |
| **Stable Diffusion** | 稳定扩散模型系列 | 常见图像生成模型系列，与潜在扩散技术密切相关。 |
| **Flow Matching** | 流匹配 | 学习连续变换所需的向量场。 |
| **Normalizing Flow** | 归一化流 | 使用可逆变换构建概率分布。 |

**区分**：Diffusion 是生成建模方法；U-Net / DiT 可以作为骨干；LDM 描述潜在空间中的扩散；Stable Diffusion 是具体模型系列。

## 9. 多模态、视觉语言与语音模型

| 缩写 / 英文名称 | 中文名称 | 核心概念 / 用途 |
|---|---|---|
| **VLM** — Vision-Language Model | 视觉语言模型 | 联合处理图像和文本。 |

## 15. 容易混淆的概念

| 层级 / 类型 | 典型名词 | 区别 |
|---|---|---|
| **任务（Task）** | 分类、检测、分割、机器翻译、跟踪 | 解决什么问题。 |
| **架构（Architecture）** | CNN、RNN、Transformer、GNN、SSM | 网络采用什么计算结构。 |
| **架构组件（Component）** | Attention、MLP、Residual、Embedding | 网络内部由什么模块构成。 |
| **模型家族（Model Family）** | ResNet、ViT、YOLO、Llama、Qwen | 使用某类设计的一系列模型。 |
| **训练方法（Method）** | MAE、DINO、LoRA、KD、DPO | 如何学习、微调或优化。 |
| **算法（Algorithm）** | PPO、SAC、SORT、K-Means | 实现学习、预测或决策的具体方法。 |
| **应用系统（System）** | RAG、Agent、多模型视觉流水线 | 如何将模型、数据和工具组合起来。 |
| **模型权重（Checkpoint）** | ResNet-50 某版权重、Qwen2.5-7B-Instruct | 最终实际加载的参数版本。 |

### 六组关系，快速理解

- **CNN = ConvNet**；**卷积**是网络可使用的运算，不是模型本身。
- **ViT** 是将 Transformer 用于视觉的架构；**DeiT、Swin** 是相关改进方向。
- **YOLO / DETR** 主要是目标检测系列；**SAM / U-Net** 主要用于分割。
- **DINO（视觉自监督）** 与 **DINO（DETR 检测）** 同名但属于不同方向。
- **Transformer** 可结合 **MoE**；MoE 并不是 Transformer 的同义词或必然替代品。
- **Diffusion** 是生成建模方法；**DiT / U-Net** 可以是扩散模型内部的网络骨干。

**学习时的四个问题**：① 输入是什么？② 输出是什么？③ 核心架构或算法是什么？④ 相比已有方法改进了什么？
