## AI 图像与视频生成提示词工程（Prompt Engineering）基础指南

### 1\. 什么是 AI 提示词工程？

AI 提示词工程（Prompt Engineering）是指通过设计结构化自然语言指令，引导生成模型产生符合预期结果的过程。

在 AI 绘图和 AI 视频生成中，提示词并不是简单的“描述想要什么”，而更像是在向一个导演、摄影师、美术师同时下达需求。

一个优秀的提示词需要明确：

-   生成什么主体
-   主体具有什么特征
-   哪些内容必须保持
-   哪些元素需要变化
-   动作如何发生
-   镜头如何表现
-   整体风格是什么

* * *

## 2\. AI 视频提示词的基本结构

一个稳定的视频生成 Prompt 通常由以下几个部分组成：

```
主体描述
+
角色保持约束
+
动作描述
+
环境变化
+
镜头语言
+
视觉风格
+
循环要求
+
负面约束
```

例如：

```
一个银白色长发少女站在夜晚城市阳台。

保持人物脸部、服装、发型完全一致。

微风吹动头发和衣服。

背景城市灯光缓慢闪烁。

镜头采用轻微手持摄影。

整体为电影级二次元风格。

生成无缝循环动画。

不要改变角色，不要改变构图。
```

* * *

## 3\. 主体描述（Subject）

主体描述负责告诉 AI：

> 画面中有什么。

需要包含：

-   人物
-   外貌
-   服装
-   姿态
-   所处环境

### 示例

低质量：

```
一个女孩
```

模型无法理解：

-   什么样的女孩？
-   什么风格？
-   什么环境？

高质量：

```
一名银白色长发的二次元少女，
佩戴蓝色水晶发饰，
穿着白色礼服，
站在夜晚城市阳台。
```

* * *

## 4\. 角色一致性约束（Identity Preservation）

AI 视频生成最大的难点：

> 保持人物不变。

如果不进行限制，模型可能：

-   改变脸型
-   改变发色
-   改变服装
-   改变饰品
-   改变人物身份

因此需要加入：

```
保持角色原始设计不变。

保持脸部、发型、服装、饰品一致。

不要改变人物身份。
```

英文常见表达：

```
Keep the character identity unchanged.

Preserve the original face, hairstyle and outfit.
```

* * *

## 5\. 动作描述（Motion）

AI 视频生成的核心是：

> 告诉模型什么运动，而不是简单说“让它动”。

错误：

```
让人物动起来。
```

正确：

```
少女轻轻眨眼。

长发随着微风缓慢摆动。

衣服和饰品产生自然晃动。

身体随着呼吸轻微起伏。
```

* * *

## 6\. 描述运动时的关键方法

### 6.1 不要描述结果，要描述过程

错误：

```
头发很漂亮。
```

正确：

```
微风吹过，靠近脸部的发丝轻微摆动，
后方长发缓慢跟随风向移动。
```

* * *

### 6.2 使用物理规律描述

AI 更容易理解：

#### 风：

```
随着风向自然摆动
```

#### 水：

```
持续起伏
```

#### 光：

```
缓慢闪烁
```

#### 呼吸：

```
轻微周期性起伏
```

* * *

### 6.3 避免抽象动作

例如：

```
腿自然摆动
```

容易失败。

更准确：

```
左腿向前移动时，右腿同时向后移动。

两条腿保持相反方向运动。

形成类似钟摆的交替运动。
```

* * *

## 7\. 镜头语言（Camera Movement）

AI 视频不仅生成画面，还需要控制摄影方式。

### 固定镜头

```
镜头保持固定。
```

适合：

-   动态壁纸
-   角色展示

* * *

### 推近镜头

```
镜头缓慢靠近人物。
```

英文：

```
slow push in
```

* * *

### 拉远镜头

```
镜头缓慢远离人物。
```

* * *

### 环绕镜头

```
镜头围绕人物缓慢移动。
```

* * *

### 手持摄影

模拟真人拍摄：

```
镜头产生轻微上下左右晃动。

模拟真实手持摄影。
```

注意：

不要只写：

```
camera movement
```

否则模型可能：

-   推近
-   拉远
-   随机移动

* * *

## 8\. 环境动态描述

静态图片变视频时，需要增加环境运动。

例如：

### 海边场景：

```
海浪持续起伏。

太阳光在海面产生波光。

云层缓慢移动。

海风吹动人物头发。
```

### 城市场景：

```
远处灯光轻微闪烁。

车辆灯光缓慢移动。

空气中存在轻微雾气。
```

* * *

## 9\. 循环视频设计（Seamless Loop）

制作动态壁纸时，需要特别强调循环。

普通：

```
生成一个循环视频。
```

效果通常不好。

推荐：

```
生成一个无缝循环动画。

所有动作必须具有周期性。

视频结束时，
人物姿态、镜头位置、光影状态、
环境变化全部回到开始状态。

最后一帧可以自然连接第一帧。
```

核心思想：

不是：

```
动作持续20秒
```

而是：

```
20秒完成一个完整运动周期
```

* * *

## 10\. 负面提示词（Negative Prompt）

负面提示用于禁止模型犯错。

常见：

```
不要改变人物。

不要改变服装。

不要改变脸部。

不要增加新物体。

不要出现手指错误。

不要出现身体变形。

不要改变构图。

不要出现镜头突然移动。
```

英文：

```
No character redesign.

No face distortion.

No outfit change.

No extra objects.

No camera movement.
```

* * *

## 11\. AI 视频 Prompt 实战模板

以后可以直接套用：

```
生成一个【时长】的视频。

保持【角色/主体】完全一致。
不要改变【脸部、服装、颜色、构图】。

【主体】位于【环境】。

【主体动作】。

【头发/衣服/饰品】随着【物理因素】自然变化。

【环境元素】缓慢变化。

镜头采用【摄影方式】。

整体风格为【视觉风格】。

生成无缝循环。
所有动作形成完整周期。

不要：
【禁止内容】
```

* * *

## 12\. AI 视频提示词设计原则总结

### 原则 1：先保证不变，再要求变化

错误顺序：

```
让人物跳舞，然后保持一致
```

正确：

```
保持人物一致，然后让人物产生动作
```

* * *

### 原则 2：动作越多，成功率越低

模型同时处理：

-   人物
-   手
-   腿
-   头发
-   镜头
-   环境

复杂度会快速增加。

建议：

优先级：

```
头发 > 光影 > 环境 > 身体 > 四肢动作
```

* * *

### 原则 3：描述物理规律比描述结果更有效

不要：

```
很自然
```

应该：

```
受到微风影响产生周期性摆动。
```

* * *

### 原则 4：中文负责创意，英文负责执行

不会英文并不是问题。

推荐流程：

```
中文构思
↓
拆分主体、动作、镜头
↓
整理结构
↓
翻译英文 Prompt
↓
测试并迭代
```

* * *

## 总结

优秀的 AI 视频提示词不是堆砌关键词，而是建立一个完整的视觉逻辑：

> 谁 → 在哪里 → 做什么 → 怎么运动 → 镜头怎么看 → 最终呈现什么感觉

AI 视频生成本质上类似导演工作。

提示词工程不是学习“神秘关键词”，而是学习如何准确描述一个画面和它的变化过程。
